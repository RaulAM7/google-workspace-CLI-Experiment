# Fase 3 — Casos de uso básicos

## Objetivo

Ejecutar flujos prácticos simples con valor de negocio real, uno por herramienta. Cada caso simula algo que un agente haría por ti en el día a día.

## Casos de uso

### Caso 1 — Gmail: Triaje inteligente de inbox
Filtrar emails no leídos por categoría de negocio (deals, propuestas, follow-ups) y extraer el contenido de uno relevante.

### Caso 2 — Drive: Buscar propuestas comerciales recientes
Encontrar documentos de propuestas por nombre y tipo, obtener links directos.

### Caso 3 — Calendar: Contexto del día para standup
Obtener agenda del día con detalle de cada evento (asistentes, descripción).

### Caso 4 — Sheets: Leer estado de un funnel de ventas
Leer datos de una spreadsheet de tracking y extraer métricas clave.

### Caso 5 — Docs: Extraer texto de una propuesta
Obtener el contenido legible de un Google Doc para resumir o analizar.

### Caso 6 — Workflow: Meeting prep completo
Usar el workflow cross-service para preparar una reunión.

### Caso 7 — Gmail + Sheets: Email-to-data
Buscar un email y extraer datos que se podrían escribir en una spreadsheet.

## Criterios de avance (de PLAN_MAESTRO)

- [ ] Al menos 5 casos de uso básicos ejecutados y documentados
- [ ] Cada caso incluye: comando, output, valoración de utilidad, fricciones
- [ ] Confianza construida en los primitivos antes de combinar
