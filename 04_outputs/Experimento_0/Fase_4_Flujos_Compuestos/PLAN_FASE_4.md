# Fase 4 — Flujos multi-paso compuestos

## Objetivo

Ejecutar flujos de negocio realistas que combinan múltiples productos de Google Workspace en una sola operación.

## Flujos a probar

### Flujo 1 — Weekly Deal Report (YA EJECUTADO en caso práctico Fase 3)
Gmail (label → hilos → contenido) + Calendar (agenda mes) + Análisis + Envío HTML automático.
Resultado: reporte Skilland MicroCred enviado a raulartilesm@gmail.com y fer@reboot.academy.

### Flujo 2 — Meeting Prep Completo
Calendar (próxima reunión con externos) + Gmail (historial con ese contacto) + Drive (docs relacionados) → briefing pre-reunión.

### Flujo 3 — Pipeline Review desde Sheets + Gmail
Sheets (leer funnel) + Gmail (buscar último contacto con cada lead) → estado actualizado del pipeline.

### Flujo 4 — Búsqueda de propuestas + resumen
Drive (buscar propuestas) + Docs (extraer texto) → resumen ejecutivo de propuestas activas.
